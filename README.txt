Machine IQ: A Practical Guide - code for the book
Keep all files in one folder.  Needs Python 3.9+, numpy, scipy  (pip install numpy scipy)

benchmarks.py        Appendix D   bands, secure band, threaded simulation
ch3_define.py        Section 3.7  window, grid, reference group
ch4_questions.py     Section 4.8  number of questions, clusters, label noise
ch5_collect.py       Section 5.7  threaded collection, retries, log and seal
ch6_score.py         Section 6.10 Brier skill, standard errors, curve fit
ch7_compute.py       Section 7.14 Phi, HIQ, profile, ceiling, bands
ch8_report.py        Section 8.11 cluster bootstrap in threads (constructed data)
ch9_long_tasks.py    Section 9.8  long-task study
ch10_monitoring.py   Section 10.8 control chart and CUSUM
ch11_buying.py       Section 11.8 break-even and acceptance test
ch12_full_study.py   Section 12.8 the whole study and its size
ch13_generality.py   Section 13.7 generality profile, biased floor, common-factor test (threads)
Run any file with:  python3 <file>.py     (benchmarks.py takes --draws, --threads, --sigma)
All data are constructed examples.
